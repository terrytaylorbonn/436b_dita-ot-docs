DITA Keys Demo: Content Reuse Made Simple

See how DITA-OT AI Assistant uses keys for consistent content reuse.

What Are Keys?

Keys in DITA allow you to define content once and reuse it everywhere. Instead of typing "DITA-OT AI Assistant" hundreds of times, you reference a key.

Simple Example

This topic demonstrates DITA-OT AI Assistant version 4.3 from the DITA Open Toolkit Project.

Key Benefits:

  • Change the product name once, update everywhere automatically
  • Maintain consistency across hundreds of pages
  • Support multiple product versions from the same source

AI Advantage

AI can automatically:

  • Detect inconsistent product names and suggest key usage
  • Update key definitions based on context
  • Validate key references across the entire document set

Before and After Keys

Before (manual repetition):

Welcome to DITA-OT AI Assistant!
DITA-OT AI Assistant helps you...
To install DITA-OT AI Assistant...

After (with keys):

Welcome to <ph keyref="product-name"/>!
<ph keyref="product-name"/> helps you...
To install <ph keyref="product-name"/>...

Result: Change one key definition, update all references instantly!
